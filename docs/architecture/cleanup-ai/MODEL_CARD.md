## 2. ארכיטקטורת המודל

- LaMa מבוסס על Fast Fourier Convolutions לשדה קליטה גלובלי, ומיועד למסכות גדולות. [ידע כללי]
- גרף ONNX יחיד, fp32, כ-209MB. [README] הגודל ב-pointer, 208,851,664 בתים, תואם. [אומת]
- **שינוי ייחודי בגרף:** יחידות ה-Fourier מחשבות FFT כמכפלות מטריצות (cos/sin בגודל הקלט) ולא כאופרטורי `DFT` של ONNX. הסיבה לפי ה-README: `DFT` לא ממומש ב-CUDA provider, ו-CPU provider איטי מאוד בגדלים שאינם חזקת 2. [README]
- דיוק מול המקור (לפי המחבר): סטייה של כ-8×10⁻⁵ ב-fp32, כלומר זניחה ב-8 ביט. [README]
- **השלכה (מסקנה שלי מהתיאור, טרם נמדדה):** מכפלות מטריצות מגדילות את העלות מהר יותר מליניארית עם גודל התמונה, ולכן ROI קטן חשוב מאוד ל-Latency.

## 3. מבנה קלט ופלט [אומת]

| פריט | ערך |
|------|-----|
| Input תמונה | `rgb`, `[1, 3, H, W]`, float, ערכים 0–1 |
| Input מסכה | `mask`, `[1, 1, H, W]`; **1 = אזור למילוי/הסרה, 0 = לשמירה** |
| מידות | H ו-W כפולות של 8 [אומת: הצורה במודל `[1, 3, '8*height', '8*width']`]. הטווח 64–4096 [README]: הכלי החזיר min/max ריקים, ולכן הוא **לא אומת** (יימדד ב-M1) |
| Output | `inpainted`, `[1, 3, H, W]`, 0–1 |
| תוכן הפלט | התמונה, כשבתוך המסכה מופיעה התחזית של ה-generator |

סטטוס: שמות (`rgb`, `mask`, `inpainted`), טיפוס float, תפקידים והאילוץ "כפולה של 8" אומתו מול הקובץ ע"י `validate_stage0.py` (פלט ההרצה אצל המשתמש). סקריפט ה-PoC ממשיך לקרוא אותם מהמודל ולא מניח.

## 4. Preprocessing ו-Postprocessing [README]

סדר הפעולות כמו ב-predict המקורי של LaMa:
1. תמונה: RGB חלקי 255. מסכה: גווני אפור חלקי 255, ו-1 היכן שהערך גדול מ-0.
2. ריפוד בצד ימין ותחתון עד כפולה של 8 בהשתקפות **symmetric** (ב-OpenCV: `BORDER_REFLECT`).
3. הרצת הגרף.
4. חיתוך הריפוד.
5. המרה ל-8 ביט: חיתוך (clip) של הערך כפול 255, וקיצוץ (truncate) ולא עיגול.

אומת ב-M1 על Big LaMa (3 דוגמאות אמיתיות, רוחב או גובה שאינם כפולות של 8): גודל הפלט זהה לקלט, והפלט הגולמי מחוץ למסכה זהה למקור (הפרש 0), כלומר נתיב הריפוד והחיתוך תקין. [אומת]

מיזוג במערכת שלנו: `orig*(1-m) + result*m`, כך שמחוץ למסכה הפיקסלים זהים למקור לבייט (ARCHITECTURE §4).

## 5. מגבלות

- אומן על חיתוכים של 256 פיקסלים, ומחזיק מעמד עד כ-2000 פיקסלים לצלע. [README]
- אסטרטגיה של מחבר ההמרה לתמונות גדולות (כנקודת פתיחה בלבד, לבדוק): עיבוד כל אזור מסכה עם הקשר בגודל האזור מכל צד ולפחות 512 פיקסלים לכל כיוון; אזור גדול מ-1536 בריבוע מוקטן לשם בהקטנה ממוצעת, ואחר כך הגדלה בחזרה ב-Lanczos. [README]
- תופעות לוואי כלליות של Inpainting: טשטוש בטקסטורות חוזרות, שכפול דפוסים, ארטיפקטים בקצוות. [ידע כללי]
