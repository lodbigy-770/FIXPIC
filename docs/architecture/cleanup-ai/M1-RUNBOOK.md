# M1-RUNBOOK – הרצת בדיקת M1 על המודל המקומי

> הכלי: `tools/m1/m1_check.py`. הוא נבדק כאן רק על מודל דמה (לא Big LaMa). הרצה ראשונה על המודל האמיתי נעשית אצל המשתמש.
> שימוש: אישי ולא מסחרי.

## דרישות
Windows, Python 3.12, git, git-lfs. אין צורך ב-GPU ואין צורך ברשת אחרי ההתקנה.

## שלבי ביצוע

### 1. קבלת המודל האמיתי (לא pointer)
```
git pull
git lfs install
git lfs pull
```
אם המודל כבר נמצא אצלך בתיקייה אחרת, אפשר להעתיק אותו ל-`models\big-lama\inpainter.onnx` או להעביר `--model <נתיב>`.

### 2. סביבה וירטואלית
```
python -m venv .venv
.venv\Scripts\activate
pip install -r tools\m1\requirements.txt
```

### 3. אימות קובץ (גודל ו-SHA256)
```
python tools\m1\m1_check.py verify
```
צפוי: שתי שורות `PASS`. אם כתוב שהקובץ הוא LFS pointer, חזור לשלב 1.

### 4. בדיקת מבנה המודל
```
python tools\m1\m1_check.py probe
```
צפוי: קלטים `rgb`, `mask`, פלט `inpainted`, וגם H ו-W דינמיים. כל שורה אמורה להיות `PASS`.

### 5. ריצה על נתוני דמה (בדיקת צנרת בלבד)
```
python tools\m1\m1_check.py run --out m1_out
```
שלוש מסכות סינתטיות: כתם, שריטה, טקסט. כאן בודקים שהכול רץ ושהפיקסלים מחוץ למסכה לא משתנים. אין כאן שיפוט איכות.

### 6. הכנת 3 דוגמאות אמיתיות
הדרך הקלה: כלי ציור המסכה. הוא פותח את התמונה, מציירים עליה את האזור להסרה ושומרים (Ctrl+S) זוג קבצים מוכן ל-`--dir samples`:
```
.venv\Scripts\python.exe tools\m1\make_mask.py "נתיב\לתמונה.jpg" --name person --out samples
```
בלי נתיב נפתח חלון בחירת קובץ. שמאלי מצייר, ימני (או E) מוחק, גלגלת העכבר משנה גודל מברשת, Ctrl+Z מבטל. `--grow 4` מרחיב את המסכה ב-4 פיקסלים בשמירה. הדרך הידנית:
צור תיקייה `samples\` ובה, לכל בדיקה, זוג קבצים עם אותו שם:
```
person.jpg   person_mask.png
text.jpg     text_mask.png
scratch.jpg  scratch_mask.png
```
המסכה: תמונה באותו גודל בדיוק של המקור, רקע שחור, והאזור להסרה צבוע לבן. כל פיקסל מעל 0 נחשב להסרה. מומלץ לצבוע מעט מעבר לגבולות העצם. תמונה לבדיקה: הסרת אדם, הסרת טקסט, הסרת שריטה. נתיבים בעברית נתמכים.

### 7. ריצה על הדוגמאות
```
python tools\m1\m1_check.py run --dir samples --out m1_out
```
אפשר לחזור עם מספר threads שונה למדידה בסיסית:
```
python tools\m1\m1_check.py run --dir samples --out m1_out_t4 --threads 4
python tools\m1\m1_check.py run --dir samples --out m1_out_t8 --threads 8
```
(`m1_out*` אינם נכנסים ל-git; `m1_out/` ב-`.gitignore`. אם משתמשים בשם אחר, אל תעשה לו commit.)

### 8. בדיקה ויזואלית
פתח את `m1_out\NAME_compare.png`: משמאל המקור, באמצע המסכה באדום, מימין התוצאה. בדוק: אין שאריות של האובייקט, אין כתם או טשטוש בולט, והמרקם ממשיך בצורה סבירה. רשום לכל אחת: טוב / סביר / גרוע.

### 9. מה לשלוח חזרה
1. הפלט המלא של שלבים 3, 4 ו-7 (העתק מהמסוף).
2. הקובץ `m1_out\m1_results.json` (זמנים, זיכרון, מפרט מחשב).
3. הערכה ויזואלית קצרה לכל אחת משלוש הדוגמאות.

מזה אעדכן `MODEL_CARD.md` (נתונים שאומתו), `DEVELOPMENT_LOG.md` ו-`ROADMAP.md`.

## קריטריוני מעבר (DoD של M1)
- `verify` ו-`probe`: כל הבדיקות `PASS`.
- `run`: כל הבדיקות `PASS` בכל הדוגמאות (צורת פלט, ללא NaN, טווח 0..1, פיקסלים מחוץ למסכה זהים אחרי מיזוג).
- תוצאה ויזואלית לא גרועה בשלוש הדוגמאות.
- הכול רץ על CPU בלבד וללא רשת.
