- שפת ממשק: עברית בלבד (RTL). כלי עצמאי לשולחן העבודה, Python ו-PySide6.

- מיזוג: `orig*(1-m) + result*m`, כך שמחוץ למסכה הפיקסלים זהים למקור.

## הצעד הבא

**החלטה נדרשת מהמשתמש:** לאשר (או לשנות) את תקציב ה-Latency המוצע (פירוט ב-`DEVELOPMENT_LOG.md`, ערך 2026-11-12): אינטראקטיבי עד קלט 256 (כ-0.8 שניות), רגיל עד 384 (כ-2 שניות), איכות עד 512 (כ-4 שניות, ידני), 768 ומעלה רק ידני. אחרי אישור יעודכנו `PLAN.md` ו-`PARITY-SPEC.md` §3/§6.

**אחר כך, בהמשך M1.5:** (1) סקריפט להשוואת OpenVINO ול-3 threads, שהמשתמש מריץ; (2) UI Spike של Zoom/Pan על 24MP; (3) אימות GIL וזמן עלייה; (4) הכרעת ADR-002, כולל שאלת גרסת Python (ה-ADR אומר 3.12, המדידות רצו על 3.14.3). אפשר גם להתחיל M2 עם התקציב המוצע ולהשאיר את OpenVINO כספייק מקביל.
