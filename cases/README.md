`mask_preview.jpg` (המקור עם המסכה באדום) ו-`case.json`.

| מקרה | גודל | מסכה | reference | מה בודקים |
|---|---|---|---|---|

**המסכות הן הערכה:** הן משוחזרות מההפרש בין המקור לתוצאה (של האתר בשני הראשונים, של הכלי בשלישי) עם `tools/m3/make_case.py`,
ולכן הן אינן בהכרח זהות לציור המקורי (למשל, מדחף ומספר נכללים ב-`table_camera` כי האתר הסיר גם אותם).

**יצירת מקרה חדש:** `python tools/m3/make_case.py ORIGINAL EDITED -o cases/NAME --reference REF`. **שמירה מהממשק:** קובץ ->
"שמירת מקרה בדיקה…" שומר את הקלט המדויק של המשיכה האחרונה (התמונה לפני, המסכה, הפרמטרים) והתוצאה הנוכחית.
